영상 → GIF 변환기

영상을 잘라서 움짤(GIF)로 만들고, 네이버 블로그 업로드 기준(10MB · 폭 966px)에 맞게 자동 압축해요.

사용 가능
🖼️

이미지 리사이즈

사진을 본문 폭(966px)에 맞게 일괄 리사이즈·압축하고, 집 주소가 드러날 수 있는 GPS 위치정보까지 자동으로 지워요.

사용 가능
✂️

썸네일 메이커

대표 이미지 규격(1:1, 800×800)에 맞게 사진을 배치하고 제목을 얹어 썸네일을 만들어요.

사용 가능
🔤

글자 수 세기

공백 포함/제외 글자 수와 원고지 매수를 실시간으로 세고, 목표 글자수 달성률을 보여줘요.

사용 가능
🚨

금칙어 검사

의료법·표시광고법 위반 소지가 있는 과장 표현과 위험 단어를 찾아 표시해요.

사용 가능
